# Política de segurança

> **Status:** ✅ atual · **Última revisão:** 2026-10-13 (#167)

**A doc oficial de segurança é [`docs/tecnico/seguranca.md`](docs/tecnico/seguranca.md)**
— reporte de vulnerabilidades, escopo, política de secrets e material
proprietário, dados locais do app, wire log e advisories tolerados vivem lá
(fonte única deste assunto).

**Resumo mínimo (a política que o GitHub lê daqui):** não abra issue pública
para vulnerabilidade — use o
[relato privado do GitHub](https://github.com/lucascantarelli/gp100-nextgen-editor/security/advisories/new)
("Report a vulnerability") ou contate o owner. Resposta esperada: 5 dias
úteis. Nenhum token/secret no repositório; material de origem da Valeton não
é distribuído (README §7).
